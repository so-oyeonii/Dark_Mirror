# 수용 테스트 / QA 체크리스트

## 프로필
- [ ] MBTI 없음/출생정보 없음으로 진행 가능
- [ ] 양력·음력·윤달 입력 유효성 확인
- [ ] 사주 엔진 없이 명식을 지어내지 않음
- [ ] 출생시간 미상 처리

## 검사
- [ ] 정확히 15개 문항, 5점 척도
- [ ] 15개 답변 전 완료 불가능
- [ ] 이전 이동 및 새로고침 후 복구
- [ ] 역문항 점수 공식 검증 (1→5, 5→1)
- [ ] 각 3문항 평균, 0~100 변환 정확
- [ ] 반복 테스트 이력 분리
- [ ] 비검증·비진단 고지

## 시뮬레이션
- [ ] 시나리오 3개 선택 가능
- [ ] 사용자 5턴 초과 거부
- [ ] 선택지 3개 또는 최대 500자 입력
- [ ] turn 중복 요청 시 중복 저장 안 됨
- [ ] 사용자 중단 즉시 작동
- [ ] API 실패/안전 이슈 상황 적절한 처리
- [ ] AI 키 없을 때 데모임을 명시

## 궁합/개인정보
- [ ] 양측 동의 전 보고서 생성/열람 거부
- [ ] 초대 링크 만료/재사용/취소 정책
- [ ] A는 B의 원본 답변·출생정보·대화 조회 불가
- [ ] 허가되지 않은 사용자의 리포트 조회 거부
- [ ] 동의 철회 후 보고서/공유 링크 접근 거부

## 카드/계정
- [ ] 1080x1920 및 1080x1080 PNG
- [ ] 원본 생년월일/시간/대화/답안 카드 제외
- [ ] 소유자 아닌 사용자 개인 결과 접근 거부
- [ ] 비회원→로그인 후 명시적 데이터 이전
- [ ] 개별 데이터/계정 삭제, 파일/공유 토큰 무효화
- [ ] 모바일 360px / 키보드 / 기본 접근성

No go-live unless: RLS policies verified; no exposed secrets; authentication redirects configured; abuse prevention/rate limits tested; privacy and deletion policy reviewed; scenario safety reviewed; saju engine validated or disabled.
