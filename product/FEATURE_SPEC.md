# 상세 기능명세서 — DARK MIRROR MVP

## 공통
한국어 UI, 360px 이상 반응형. 비회원 시험 진행 가능. 소유자와 명시적 동의 없는 데이터 공개 금지. 출생정보·원문 대화·답안은 기본 비공개.

### F01 MBTI·사주 기본 프로필
닉네임 2~20자. MBTI 16종 또는 미입력. 생년월일/시간 선택 입력; 양력/음력·음력 윤달 여부·출생 시간대(기본 Asia/Seoul). 날짜 유효성 검사. 출생시간 없으면 시주를 계산하지 않으며 그 한계를 표기. 사주 엔진이 검증되기 전에는 명식을 꾸며내지 말고 `계산 준비 중`으로 표시. MBTI와 사주 해석은 엔터테인먼트로 별도 섹션.

### F02 15문항 관계 성향
`product/QUESTIONS.json` 참고. 5개 차원 × 3문항, 1~5 리커트, 역문항은 6 - raw. 차원별 `((3개 수정 응답 평균 - 1)/4)*100`, 소수 1자리. 모든 문항을 답해야 완료. 결과에 5차원 시각화, 설명, 성찰 질문, 비진단 고지. 동일 계정 재검사는 새로운 attempt로 보존.

### F03 AI 시뮬레이션 3종
`LOVE`, `FRIEND`, `WORK`. 각 사용자 답변 5턴, 선택지 3개 또는 최대 500자 자유 입력. 서버가 세션 상태·턴 번호 검증, 중복 요청 방지. AI 응답 JSON 검증. 중단 버튼 항상 노출. 5턴 후 중립적 피드백: 관찰된 대화 행동, 표현한 감정·경계, 대안 답변, 성찰 질문. 조종/가스라이팅 여부 진단 및 악의적 기술 상세 지시는 제공하지 않음. 비밀키 서버 보관. 모델 미연결 시 *명시적인 데모 모드*로만 진행.

### F04 2인 궁합
A 초대→B 로그인/프로필→각자 공유할 항목 체크→양쪽 동의 확인→보고서. 72시간 만료 일회성 토큰은 무작위 생성하고 해시만 DB 저장. 원본 생년월일·시간, 답변, 채팅 내용 상대에게 제공하지 않음. MBTI·사주 관계 이야기는 재미 요소, 행동 성향 비교는 별도 섹션. 백분율 종합 궁합 점수 금지. 언제든 철회/삭제 가능하고 캐시/공유까지 무효화.

### F05 공유 카드
1080×1920, 1080×1080 PNG. 기본 닉네임 숨김. 종류: 캐릭터, 5차원 프로필, 사주·MBTI 해석, 2인 궁합(양쪽 공유 동의 필요). 이미지 안에 생년월일, 출생시간, 자유 입력, 원본 답안 절대 넣지 않음. 링크는 별도 공개 토큰/만료/철회 가능하며 개인 결과 원본으로 직접 이어지면 안 됨.

### F06 계정·저장
Supabase Auth 이메일 매직 링크(기본). 비회원 로컬 임시 결과를 로그인 후 명시적 확인을 받아 이전. 결과/AI 세션/궁합/공유 카드 내역 조회 및 개별 삭제, 전체 계정 삭제. 삭제 후 외부 공개 URL도 작동하지 않아야 함. RLS·서버 소유권 검사.

## 성능/사용성/접근성
일반 API p95 <1초, AI p95 <12초는 초기 목표(보장 아님). 실패/재시도/로딩 표시. 사용자 활동 로그에는 민감한 텍스트 기록 배제. 키보드·스크린리더 접근성 준수.
