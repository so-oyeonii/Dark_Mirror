# 제품 요구사항 (PRD) v1.0

## 포지셔닝
**DARK MIRROR**: 운명을 읽고, 성격을 발견하고, 관계를 경험하다. 재미로 접하는 사주·MBTI와 행동 기반 자기성찰 테스트를 구분하고, AI 시뮬레이션으로 관계 대처를 연습하는 모바일 우선 웹앱.

## 사용자 가치
- 첫 방문자는 로그인 없이 15문항 테스트와 결과를 체험한다.
- 사용자는 선택적으로 MBTI/출생정보를 입력하고 자신만의 프로필을 본다.
- AI와 연애·우정·직장 3개 맥락의 짧은 관계 시나리오를 체험한다.
- 친구/연인이 서로 동의한 정보만 활용하여 2인 비교 리포트를 본다.
- 개인정보가 제외된 결과 카드만 공유한다.
- 로그인 사용자는 결과 이력 및 삭제 기능을 가진다.

## 퍼널
`랜딩 → 프로필(건너뛰기 가능) → 15문항 → 결과 → [AI 체험 | 궁합 초대 | 공유] → 계정에 저장`

## 내비게이션
홈, 심리 테스트, AI 체험, 궁합, 마이.

## 범위
포함: MBTI 선택, 양/음력 출생정보 선택 입력과 검증된 사주 엔진 연동 구조, 15문항 및 5차원 채점, AI 3종 5턴 대화, 상호동의 궁합, PNG 카드, 이메일 인증/결과 저장/삭제.
제외: SNS 피드, 유료 결제, 푸시 알림, 랭킹, 진단/치료, 조종 기술 코칭, 운세 정확도 주장.

## 우선 지표
테스트 완료율, 테스트→AI 체험 시작률, 공유 링크 유입률, 7일 재방문율, API 실패율. 분석 이벤트는 개인 대화/출생정보 원문을 전송하지 않는다.
