# DARK MIRROR — Phase 1 화면 설계

## 방향
차분한 잉크 블루 화면 위에 은빛 거울의 형태를 하나의 시각적 중심으로 둔다. 타인을 판정하는 도구처럼 보이기보다, 관계 속 자신의 반응을 돌아볼 수 있는 조용한 공간을 만든다. 모바일에서 한 번에 한 가지 행동에 집중한다.

## 디자인 토큰
- 배경 `#142331`: 깊은 잉크 블루.
- 표면 `#1D3143`: 폼과 필요한 정보 묶음.
- 본문 `#F0F3F6`: 옅은 은빛.
- 보조 본문 `#B7C6D4`: 충분히 읽히는 청회색.
- 강조 `#D4E4EF`: 주요 행동과 거울의 테두리.
- 오류 `#FFB8AE`: 오류 문구와 경고.

한국어 시스템 글꼴(`Apple SD Gothic Neo`, `Malgun Gothic`, sans-serif)을 사용한다. 외부 폰트 다운로드에 의존하지 않는다. 본문 16px, 행간 1.7, 모바일 제목 32~42px를 기본으로 한다. 버튼과 폼 조작 영역은 최소 44px이다.

## 레이아웃
앱 전체는 상단 브랜드, 읽기 폭을 제한한 본문, 하단 5개 탭으로 구성한다. 본문은 왼쪽 정렬하고, 데스크톱에서도 폼은 한눈에 읽을 수 있는 폭을 유지한다. 랜딩만 넓게 열어 소개와 거울 형태를 함께 배치한다.

```text
모바일                 넓은 화면
[브랜드 / 데모]        [브랜드                     데모]
[지금의 나를...]       [소개 + 시작 버튼] [거울 형태]
[시작 / 둘러보기]      [서비스 소개 / 개발 상태]
[거울 형태]            [내 정보에 대한 안내]
[서비스 소개]
[홈 테스트 AI 궁합 마이 — 고정 하단]
```

## Phase 1 상태와 문구
- 랜딩 주 행동은 `프로필 시작하기`. 보조 행동은 `먼저 둘러보기`로 페이지 안의 소개에 연결한다.
- MBTI·출생정보는 선택이며 게스트 이용 안내를 함께 둔다.
- 검사, AI, 궁합 경로는 실제 준비 중 화면을 제공한다. 검사가 이미 가능하다고 약속하지 않는다.
- 앱의 현재 범위는 `로컬 데모`. 계정 인증 상태와 구별하며, 각 기능 화면에서 세부 제한을 설명한다.
- 사주와 MBTI는 재미 요소이며, 행동 성찰과 섞어 점수를 만들지 않는다.

## 브리프 대비 자체 검토
검정+네온 색상, 매 구역 동일 카드, 장식용 숫자, 자동 애니메이션은 채택하지 않았다. 거울 형태에만 시각적 개성을 주고 폼과 내비게이션은 예측 가능하게 유지한다. `운명을 읽는다`는 기존 포지셔닝을 사실 주장으로 확대하지 않고, 관계 속 자신을 돌아본다는 구체적인 소개를 사용한다. 원본 기획 문서는 수정하지 않는다.

## 접근성 및 반응형 검수 기준
- 360px에서 가로 넘침 없음. 하단 탭 높이와 기기 안전영역만큼 본문 여백 확보.
- 건너뛰기 링크, 현재 탭 `aria-current`, 아이콘과 텍스트 병기, 명확한 포커스 표시.
- 제목은 페이지마다 하나의 h1. 장식용 거울과 아이콘은 보조기기에서 숨김.
- 오류는 색상 외 텍스트로 안내. 입력 요소는 label 및 설명 연결을 사용.
- 자동 움직임 없음. 사용자 감소된 움직임 설정 존중.
- 구현 후 실제 브라우저 검사 결과는 별도 검증 보고에 기록하며, 이 계획 자체는 통과 증빙이 아니다.
