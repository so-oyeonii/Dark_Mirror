## 공통 범위

사주 엔진 검증 → 게스트 사주·MBTI 결과 → 안전한 카드 확장 → 실제 AI 연결 준비 순서로 진행한다. 로그인·서버 개인기록 저장·실제 2인 초대·공개 배포는 이번 세션 범위에 포함하지 않는다. 사주를 임상 진단/미래 사실처럼 표현하지 않고 관계 테스트 점수에 섞지 않는다. 기존 질문/시나리오/기획 원본과 테스트 흐름을 보존한다.

작업 폴더는 같은 비 Git 폴더이므로 변경은 즉시 공유된다. 다른 팀원의 작업을 되돌리거나 소유권 없는 파일을 수정하지 않는다. 전체 build/typecheck/E2E 서버는 총괄만 실행한다. 각 세션은 담당 unit tests와 파일별 lint를 실행할 수 있다. 필요한 공통 변경은 세션의 최종 보고 또는 자기 담당 문서에 제안한다. 사용자는 별도 세션 작업 진행을 승인했으며, 총괄은 해당 세션의 진행을 읽고 업무에 필요한 후속 지시를 전달한다.

## 엔진 ↔ 화면 계약

`src/lib/saju-contract.ts`의 `CalculateSaju` 계약대로 `src/lib/saju.ts`에서 `calculateSaju`를 export한다. 브라우저에서 호출할 수 있는 비동기 함수이며 출생 원문을 외부로 전송하지 않는다. 입력은 기존 Profile 그대로 받는다. 검증된 범위에서만 ready를 반환하고 missing/unsupported/error는 설명과 함께 표시한다. 출생시간 미상은 hour=null이며 절기/일주 경계에서 불확실하면 값을 꾸미지 않는다.

천간·지지 표시는 한글/한자 독자가 이해할 문자열로 한다. elements는 표시한 천간과 지지의 대표 오행 개수이며 지장간/강약/길흉을 뜻하지 않는다. 적용 시간대, 절기 기준, 날짜 전환, 시간 미상 처리, 오행 집계 기준은 conventions/warnings와 엔진 문서에 기록한다. 정확하지 않은 입력 범위는 명시적으로 거절한다.

## UI와 카드

게스트 프로필로 /profile에서 사주·MBTI를 살펴볼 수 있게 한다. 입력은 기존 /onboarding을 재사용하고 저장 후 /test로 향하는 기존 흐름은 보존한다. 홈과 마이에 명확한 프로필 보기 링크를 추가한다. 생일/시간/이름/원본 답안/대화는 공유 이미지에 넣지 않는다. 사주 명식 자체도 역추론 위험을 고려해 카드에는 넣지 않고, 공유 동의한 오행 요약과 선택적 MBTI 이야기만 허용한다. 카드 크기 1080×1080/1080×1920, 저장 동의 기본 false, 삭제/만료/이동 후 늦은 다운로드 취소를 유지한다.

## 완료 기준

계산 근거/라이선스/검증 fixture 출처와 지원 범위를 기록한다. 엔진값을 동일 엔진의 출력으로만 대조하지 않는다. 음력 윤달·절기·시간 미상·23시/자정 경계·지원 시간대·오류를 테스트한다. 사용자 데이터 원격 전송 없음, 저장/만료/삭제 후 결과 무효화, 모바일 360px와 접근성, 기존 127 unit/50 E2E 회귀를 총괄이 확인한다. 근거가 부족한 범위는 미검증 상태로 남기되 검증된 입력의 실제 계산 기능을 우선 완성한다.
